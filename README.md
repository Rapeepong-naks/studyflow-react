# StudyFlow

StudyFlow is a React and Vite project for a personal study planner. The app is at the starter stage; planned features include courses, tasks, filters, a dashboard, and a local REST API.

## Run locally

Install Node.js and npm, then run:

```bash
npm install
npm run dev
```

Open the URL printed by Vite. The current screen is the Vite starter UI while the app is being built.

## Project files

- `src/` — React application code
- `public/` — static assets
- `db.example.json` — sample data for the planned local API
- `.env.example` — sample API URL

Local learning notes and course materials are kept outside the published repository. `node_modules/`, build output, `.env.local`, and `db.json` are also excluded from Git.
